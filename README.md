# 🌦 Weather Console App

Консольное приложение на Python для получения текущей погоды по названию города с использованием Open-Meteo API.

---

# 📌 Описание

Программа позволяет:

- ввести название города;
- автоматически получить его координаты;
- запросить текущую погоду через API;
- вывести:
  - температуру;
  - скорость ветра;
  - направление ветра.

Приложение работает в терминале и не требует API-ключа.

---

# ⚙️ Используемые технологии

- Python 3
- requests
- Open-Meteo API

---
