# 🌦 Weather Console App

Консольное приложение на Python для получения текущей погоды по названию города с использованием Open-Meteo API.

---

# 📌 Описание

Программа позволяет:

- ввести название города;
- автоматически получить его координаты;
- запросить текущую погоду через API;
- вывести:
  - температуру;
  - скорость ветра;
  - направление ветра.

Приложение работает в терминале и не требует API-ключа.

---

# ⚙️ Используемые технологии

- Python 3
- requests
- Open-Meteo API

# 🔧 Описание функций

## `get_coordinates(city_name)`

Получает координаты города через Geocoding API Open-Meteo.

### Параметры:

- `city_name` — название города.

### Возвращает:

```python
{
    "lat": latitude,
    "lon": longitude,
    "name": city_name,
    "country": country_name
}
```

---

## `get_weather(lat, lon)`

Получает текущую погоду по координатам.

### Параметры:

- `lat` — широта;
- `lon` — долгота.

### Возвращает:

```python
{
    "temperature": value,
    "windspeed": value,
    "winddirection": value
}
```

---

## `main()`

Основная функция программы.

### Выполняет:

1. Ввод города;
2. Поиск координат;
3. Получение погоды;
4. Вывод информации в консоль.

# 🌐 API

## Geocoding API

Используется для поиска координат города.

```text
https://geocoding-api.open-meteo.com/v1/search
```

---

## Forecast API

Используется для получения текущей погоды.

```text
https://api.open-meteo.com/v1/forecast
```
